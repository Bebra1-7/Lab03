# ПР3. Ответы на контрольные вопросы
    1. Разницы нету, а отличие в том, что не надо писать два раза подряд переменную.
    2. Между x++ and ++x разница в том, что x++ прибавляет после к примеру вывода на консоль, а ++x сразу прибавляет и выводит готовый result.
    3. Получается bool тип данных.
    4.  «короткое замыкание» в && и ||. Оно возникает когда один из элементов к примеру в && равен false, то 2-ой элем. уже не будет проверяться, а ||, если один из элем. равен true, то др. элем. не будет проверяться(пример: 1. (1 == 0 && 1 == 1); 2. (1==1 || 1 == 0)).
    5. 10 - 2 * 3 + 4 / 2
        1. 4 / 2 = 2
        2. 2 * 3 = 6
        3. 10 - 6 = 4
        4. 4 + 2 = 6
    6. Это упрощает и помогает, прочитать операцию для пользователя.
